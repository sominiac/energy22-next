## Energy22-next
Проект созданный под SEO оптимизацию вёрстки react приложения.

В проекте используется фреймворк Nextjs для кеширования ассетов и создания статического билда.
Все остальные инструменты не изменились в соответствии с [репозиторием react приложения](https://github.com/sominiac/energy22-new).

Демо страница проекта - https://sominiac.github.io/energy22-next

### Версия 0.1.1

В данной версии реализовано создание статических файлов билда.
Работает вся логика проекта учитывая, что для него не предусмотрена backend составляющая с хранением данных.
Все данные хранятся внутри самого проекта.
